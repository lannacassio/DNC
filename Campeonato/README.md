# Construindo um Painel do Campeonato Brasileiro na Indústria Esportiva no Power BI

## Contexto

O objetivo é utilizar os dados do dataset para criar um painel (dashboard) com visualizações que respondam às perguntas específicas sobre o campeonato brasileiro. 

Para isso, será necessário analisar os dados fornecidos no dataset, como times participantes, placares, pontos, etc. 
O dashboard deve permitir a visualização das informações de forma clara e intuitiva, facilitando a interpretação dos resultados e a tomada de decisão com base nas análises.

### Perguntas ao qual devemos tentar responder
a. Qual time visitante com maior número de gols

b. Qual time mandante com maior número de gols

c. Qual o número de gols visitante e mandante ao decorrer do mês e a média dos gols.

d. Uma tabela contendo todos os técnicos.

e. Qual estado visitante com maior número de gols

f. Qual estado mandante com maior número de gols

g. Qual os 5 maiores times mandantes com maior número de gols

h. Qual os 5 maiores times visitantes com maior número de gols
